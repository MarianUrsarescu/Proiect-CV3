# Proiect-CV3
# Clasificarea speciilor de flori utilizând metode de Machine Learning și Deep Learning

Acest proiect urmărește dezvoltarea unui sistem de clasificare automată a speciilor de flori, utilizând atât metode clasice de Machine Learning, cât și tehnici de Deep Learning. Pentru antrenarea și evaluarea modelelor va fi utilizat setul de date **Oxford 102 Flower Dataset**, care conține peste 8.000 de imagini distribuite în 102 clase distincte. Inițial, vor fi implementate metode precum **Bag of Words (BoW)**, împreună cu algoritmii **K-Nearest Neighbors (KNN)** și **Support Vector Machine (SVM)**, dar și arhitecturi de rețele neuronale convoluționale precum **ResNet18** și **AlexNet**, existând posibilitatea extinderii către alte metode de clasificare. Performanțele modelelor vor fi analizate prin intermediul acurateței, matricilor de confuzie și al evoluției procesului de antrenare. Implementarea va fi realizată în Python, utilizând biblioteci precum PyTorch, Scikit-learn și OpenCV, iar antrenarea și testarea modelelor se vor desfășura local, pe un calculator personal. Scopul principal al proiectului este compararea performanțelor diferitelor metode și identificarea celor mai eficiente soluții pentru recunoașterea automată a speciilor de flori.
